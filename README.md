# Algoritmit ja tekoäly harjoitustyö

Kyseessä 2048 pelin ratkaiseva tekoälytoteutus hieman muunnellulla expectiminimax algoritmilla ja sitä auttavalla heurestiikalla joka pohjaa pelin suosittuun taktiikkaan.

[määrittelydokumentti](https://github.com/lowdodo/algoritmit-ja-tekoalyharjoitustuo/blob/main/dokumentaatio/maarittelydokumentit.md)
[toteuttusdokumentti](https://github.com/lowdodo/algoritmit-ja-tekoalyharjoitustuo/blob/main/dokumentaatio/toteutusdokumentaatio.md)

## Käynnistys:

Alusta peli koneellesi

Asenna riippuvuudet

```
poetry install
```

pelaa:

```
poetry run invoke start
```

## Testaus

unit testit voidaan suorittaa komennolla

```
poetry run invoke test
```
